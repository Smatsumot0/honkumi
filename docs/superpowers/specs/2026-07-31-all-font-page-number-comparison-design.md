# 全フォント・ノンブル無補正比較PDF 設計

## 目的

既存のPDF出力には、本文フォントとノンブル用フォントごとのサイズ補正がある。アプリ本体の挙動は変更せず、その補正を外した状態で本文より1pt小さいノンブルを確認できる比較PDFを生成する。

## 対象

- 本文フォント5種類
- ノンブル用フォント8種類
- 合計13 PDF

既存の全フォントサンプルと同じ本文、用紙、組版、目次、章見出し、奥付を使用する。本文サイズは9pt、本文下部のノンブルは8ptとする。

## 生成方式

現在のワークスペースを一時ディレクトリへコピーし、その一時コピーだけを変更してDebugビルドを行う。元のワークスペースにあるアプリ本体のSwiftコード、設定、既存成果物は変更しない。

一時コピーでは次の条件を適用する。

1. 本文フォントに設定されたノンブル用PDFサイズ補正を0にする。
2. ノンブル用8フォントに設定されたPDFサイズ補正を0にする。
3. 全フォントサンプルのノンブル設定サイズを本文サイズから1pt引いた値にする。
4. 目次内のページ番号についても、フォント別のサイズ補正を外して素のフォント差を比較できるようにする。

本文中の約物、長音、目次本文など、ノンブル以外の既存補正は維持する。

## 出力

最終成果物は `output/pdf/AllFontSamples-NoAdjust-BodyMinus1pt-2026-07-31/` に13 PDFを保存する。同じ内容をZIPへまとめ、`output/pdf/` に配置する。ファイル名は既存の全フォントサンプル名を維持する。

## 検証

- PDFが13件あり、本文5件とノンブル用8件に分かれていることを確認する。
- 各PDFを再度開き、ページ数と基本的なPDF構造を確認する。
- 全PDFをPNGへレンダリングし、ノンブル、目次、本文、章見出し、奥付に欠け、重なり、文字化け、ページ外へのはみ出しがないことを目視確認する。
- 比較ビルド終了後、元のワークスペースにアプリ本体の差分が増えていないことを確認する。

## エラー処理

ビルド、Simulator起動、PDFコピー、レンダリングのいずれかが失敗した場合は成果物を完成扱いにしない。原因を切り分けて再実行し、13 PDFすべての検証が通った時点で成果物を渡す。
