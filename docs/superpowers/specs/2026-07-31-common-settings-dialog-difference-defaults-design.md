# 共通設定適用ダイアログの差分初期選択設計

## 目的

共通設定の変更後に作品を開く際の適用確認ダイアログについて、作品設定と現在の共通設定が異なる分類だけを初期状態でオンにする。共通設定と一致する分類はオフにする。

## 確定した挙動

- 比較単位は既存ダイアログと同じ「エディタ設定」「サークル設定」「フォーマット設定」「印刷設定」の4分類とする。
- ダイアログを表示する時点で、対象作品の現在設定と現在の共通設定を比較する。
- 各分類について、共通設定をその分類だけ作品へ適用した結果が適用前と異なる場合はオン、一致する場合はオフにする。
- 共通設定の変更履歴は保存せず、未確認だった過去の変更も累積しない。
- 作品側で独自に変更した結果として共通設定と異なる分類もオンになる。この方式の意図した挙動として扱う。
- アップデート前から未確認だった既存作品は、変更分類を復元できないため最初の確認だけ全分類オンにする。
- 既存作品が移行時点の変更を確認した後に発生する新しい確認では、通常の差分比較を使用する。
- 利用者はダイアログ表示後に各分類を自由にオン・オフできる。
- 全分類がオフの場合は、既存どおり「適用して開く」を無効にする。

## 設計

### 差分判定

`EditorSettings` に、対象作品設定と共通設定から `UserDefaultSettingsSelection` を生成する差分判定を追加する。

差分判定では、分類ごとのフィールド一覧を新たに重複定義しない。既存の `applyingUserDefaults(_:selection:)` を各分類単独で呼び出し、その結果を適用前の検証済み作品設定と比較する。これにより、初期選択の範囲と実際の適用範囲を常に一致させる。

サークル設定では、既存の選択適用がコピーする発行者情報だけを比較対象とする。作品固有の奥付項目は差分判定へ含めない。

### 確認要求と表示

`DocumentStore.userDefaultSettingsReviewRequest(for:)` は、対象作品と現在の共通設定から初期選択を算出し、確認要求へ含める。ただし、対象作品が移行時点の共通設定リビジョンより古い場合は、既存データの互換動作として `.all` を使用する。

`CommonSettingsReviewPresentation` は、固定値 `.all` ではなく確認要求が持つ初期選択で生成する。`WorkListView` は引き続き確認要求からプレゼンテーションを作るだけとし、差分ロジックをUIへ持たせない。

確認要求のリビジョン検証、適用・見送り処理、背景操作防止、アクセシビリティ、ダイアログの高さは変更しない。

### 既存データの移行境界

`AppData` に、アップデート時点の共通設定リビジョンを表す任意の移行境界値を追加する。新フィールドを持たない既存保存データの復号時だけ、そのデータの現在リビジョンを境界値として設定する。新規データでは境界値を持たない。

作品の確認済みリビジョンがこの境界値より古い場合、その作品には変更分類を特定できない既存の未確認変更が残っているため、全分類オンで表示する。適用または見送りによって確認済みリビジョンが更新された後は境界条件から外れ、以後の確認では作品設定と共通設定の差分を使用する。

これは分類別の変更履歴を保存するものではない。移行前の不明な変更に対する一度限りの互換用境界である。

### 全分類一致時

共通設定リビジョンが進んでいても、対象作品が現在の共通設定と全分類で一致する場合がある。この場合も既存のリビジョン確認フローに従ってダイアログを表示し、全分類オフで開始する。「適用して開く」は無効となるため、利用者は「適用せず開く」または「キャンセル」を選べる。必要であれば分類を手動でオンにして適用できる。

## データフロー

1. 利用者が未確認リビジョンを持つ作品を選ぶ。
2. `DocumentStore` が移行境界より古い既存作品かを判定する。該当すれば全分類を選択し、該当しなければ作品設定と現在の共通設定を4分類ごとに比較する。
3. `UserDefaultSettingsReviewRequest` が算出済みの初期選択を保持する。
4. `CommonSettingsReviewPresentation` がその選択でダイアログを初期化する。
5. 利用者が必要に応じて選択を変更し、既存の選択適用または見送り処理を実行する。

## エラー処理と互換性

- 差分判定は値型の同期比較だけで完結し、新しい失敗経路を追加しない。
- 比較前後で既存の `validated` を使用し、保存時の正規化差だけを変更として誤判定しないようにする。
- 移行境界値は後方互換な任意フィールドとして追加し、既存データでは欠落時に現在リビジョンを採用する。
- 新規データおよび新しい共通設定セッションでは、分類別の履歴を永続化しない。

## テスト

- 4分類それぞれについて、その分類だけが異なる場合に対象だけオンになること。
- 複数分類が異なる場合に、それらだけがオンになること。
- 全分類が一致する場合にすべてオフになること。
- サークル設定では共有する発行者情報の差だけを検出し、作品固有の奥付項目の差は無視すること。
- 共通設定の過去変更を見送っていても、現在値が一致する分類はオフになること。
- 新フィールドを持たない既存データでは、移行時点から未確認の作品だけが全分類オンになること。
- 移行時点の変更を確認した作品では、次回から差分選択へ切り替わること。
- 確認要求の初期選択がダイアログ表示へ引き継がれること。
- 手動で選択を変更した後の既存適用処理と、全解除時の適用無効化が維持されること。
- 関連する共通設定セッション、確認処理、表示、保存互換性の既存テストが通ること。

## 対象外

- 共通設定の分類別変更履歴またはリビジョン履歴の保存。
- 未確認だった複数セッションの変更分類の合算。
- ダイアログの文言、レイアウト、操作方法の変更。
- 作品固有設定と共通設定の競合を説明する追加UI。
