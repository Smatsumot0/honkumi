# サークルロゴ表示サイズ変更 設計書

## 目的

奥付に表示するサークルロゴを、余白を除いた本文領域内で現在より大きく表示する。ロゴの縦横比を維持し、本文領域の左右の余白へはみ出さないようにする。

## 表示仕様

ロゴを次の上限を持つ矩形へアスペクトフィットする。

- 最大幅：本文領域幅の50%
- 最大高さ：横書き奥付で使う行高の4行分

画像の縦横比は変更しない。横長画像は原則として最大幅へ、縦長画像は原則として最大高さへ合わせ、もう一方の寸法を縦横比から算出する。正方形を含め、両方の上限内で可能な最大サイズを使用する。

ロゴは現在と同様に本文領域の水平方向中央へ配置する。描画矩形の左右端を本文領域内に収め、用紙の余白にはみ出させない。

## 実装構成

ロゴの元画像サイズ、本文領域幅、奥付の行高から、描画サイズを計算する小さな純粋レイアウト処理を追加する。PDF描画処理はこの計算結果を使い、画像を高品質補間で描画する。

奥付全体の高さ計算にも同じ描画サイズを使用する。ロゴが幅上限によって4行分より低くなる場合は、その実際の高さを基準に後続項目を配置する。ただし既存どおり、奥付項目として最低1行分の高さは確保する。これにより、ロゴと後続項目の重なりや不要な4行分の空白を防ぐ。

対象は既存のサークルロゴ付き奥付PDF描画とし、ロゴの保存形式、アップロード処理、設定UI、作者・サークル行の表示条件は変更しない。

## 無効画像の扱い

画像データを読み込めない場合は、既存動作どおりロゴを描画しない。ゼロ以下または有限でない画像寸法はレイアウト計算の対象外とし、不正な描画矩形を生成しない。

## テスト方針

TDDで、実装前にサイズ計算の失敗テストを追加する。

- 横長画像が本文領域幅の50%に収まり、高さが縦横比に従うこと
- 縦長画像が4行分の高さに収まり、幅が縦横比に従うこと
- 正方形画像が両方の上限を超えない最大サイズになること
- 描画幅が本文領域幅の50%以下で、中央配置時に本文領域からはみ出さないこと
- ロゴの実寸高が奥付の項目高へ反映されること

対象テストの通過後、関連する奥付テストとアプリのビルドを実行する。

## 完了条件

- ロゴが本文領域幅の50%と奥付4行分の両方を上限として最大表示される。
- ロゴの縦横比が維持される。
- ロゴが本文領域中央に配置され、余白へはみ出さない。
- 後続する奥付項目がロゴと重ならない。
- 既存のロゴ読み込み、表示条件、PDF生成が回帰しない。
