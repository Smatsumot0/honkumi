# 入力時フォーマット・共通設定同期・SVGロゴ設計

## 目的

次の操作を、長い本文での入力性能と既存作品の個別設定を維持しながら改善する。

- 「本文入力時に自動フォーマット」がオンの場合、日本語入力の変換確定後から入力位置周辺を即時フォーマットする。
- 作品設定の変更中は本文を変更せず、設定画面を閉じた後に必要な全文フォーマットを1回だけ行う。
- 共通設定が変更された後に既存作品を開く場合、共通設定を適用するか利用者へ確認する。
- サークルロゴにSVGを追加し、ロゴ選択UIを中央の角丸表示へ変更する。

## 現状と原因

本文入力中の`ManuscriptTextEditor`は、確定済み文字列をそのまま`DocumentStore`へ保存し、現在は編集終了時にだけ本文全体をフォーマットしている。このため、自動フォーマットをオンにしても入力直後には反映されない。

作品設定では、フォーマット設定の変更ごとに`SettingsViewModel`が本文全体の非同期フォーマットを開始する。長い本文では設定操作中にも処理が発生し、利用者が設定を続けて変更すると不要な処理と破棄対象の結果が増える。

共通設定は新規作品の初期値には使われるが、既存作品が最後にどの共通設定を確認したかを記録していない。単純に現在値を比較すると、利用者が意図して変更した作品固有設定まで、毎回「未適用」と誤判定してしまう。

サークルロゴのファイル選択は画像一般を対象にしているが、SVGを明示しておらず、保存後の検証・プレビュー・PDF描画も`UIImage(data:)`で直接扱う前提になっている。また、選択方法に`confirmationDialog`を使っているため、端末と表示位置によって吹き出し型へ適応される。

## 採用する構成

処理を次の4つの責務へ分ける。

1. `ManuscriptLiveFormatter`
   - 入力位置周辺だけを同期的に整形する純粋な処理。
   - 本文、変更範囲、選択範囲、設定、Pro状態を受け取り、整形後本文と選択範囲を返す。
2. `ManuscriptFormattingCoordinator`
   - 本文全体の非同期フォーマット、進捗状態、世代管理を担当する。
   - 設定画面を閉じた後、共通設定を適用した後、または必要なPro状態変更後にだけ起動する。
3. 共通設定の更新番号
   - 共通設定の変更履歴と、作品ごとの最終確認状態を永続化する。
4. `CircleLogoImageImporter`
   - 通常画像の検証とSVGの透過PNG変換を同じ保存境界へまとめる。

`DocumentStore`は作品と設定の永続化元のままとし、入力中の局所整形と全文整形の実行責務は持たせない。

## 入力中の即時フォーマット

### 適用タイミング

`ManuscriptTextEditor`は`UITextViewDelegate`から変更予定範囲を記録する。`markedTextRange`が存在する日本語変換中は本文を整形しない。変換が確定して`markedTextRange`がなくなった時点で、その変更範囲を`ManuscriptLiveFormatter`へ渡す。

次の入力経路を同じ扱いにする。

- キーボード入力と削除
- 日本語入力の変換確定
- 貼り付け
- エディタ下部ツールバーからの文字・タグ挿入

音声入力やシステム置換など、変更予定範囲を取得できない確定変更では、確定後の選択位置を基準に局所範囲を決める。

### 整形範囲

入力ごとに本文全体を走査しない。変更された文字を含む行を中心に、各ルールの判定に必要な隣接文字と隣接行だけを範囲へ含める。

- 句読点、括弧、三点リーダー、ダッシュ、感嘆符・疑問符は、変更箇所の前後を含む現在行で判定する。
- 閉じかっこ前の句点は、変更箇所から閉じかっこまでを同じ局所範囲へ含める。
- 連続空行と改ページタグは、変更箇所に連続する空行群と、その前後の境界行を含める。
- 半角スペース整理は変更対象行だけへ適用する。

局所文字列には既存の`ManuscriptFormatter`と同じルール順序を適用する。無料・有料ルールの権限判定も既存の`FormatOptions`を使い、無料状態で有料ルールを実行しない。

### カーソルと表示位置

局所整形で文字数が変わる場合、置換範囲より前、範囲内、範囲より後の3領域に分けて選択位置を補正する。整形後のカーソルは、利用者が確定した入力の直後を維持する。

`UITextView`のスクロール位置は整形前に保存し、置換後も同じ位置を復元する。カーソルが表示領域外へ出た場合だけ、既存の選択範囲表示処理で必要最小限追従する。

編集終了時に行っている本文全体の自動フォーマットは削除する。キーボードを閉じただけでは、進捗表示のない全文処理を開始しない。

## 作品設定を閉じた後の全文フォーマット

### 設定画面内

作品設定画面を開いた時点で、次を設定セッションのスナップショットとして保持する。

- 作品ID
- フォーマット設定
- Pro状態

設定画面内ではフォーマット設定を保存するが、本文全体のフォーマットを開始しない。画面内に現在ある「本文にフォーマットを適用中…」表示は削除する。

### 設定画面を閉じた時点

設定画面を閉じた後、次の条件をすべて満たす場合に限り全文フォーマットを1回要求する。

- 作品ごとの設定画面である。
- 開いた作品と閉じた時点の作品が同じである。
- フォーマット設定、または適用可能なPro状態がセッション開始時から変化している。
- 閉じた時点で「本文入力時に自動フォーマット」がオンである。

ルールをオフにしただけの場合は、他の有効ルールを再適用するための不要な全文処理を行わない。全文処理の対象は、自動フォーマットをオンにした場合、個別ルールをオンにした場合、有効なルールの空行上限などを変更した場合、または無料から有料へ変わって有効な有料ルールが利用可能になった場合とする。

無料から有料への変更が設定画面内の購入操作で起きた場合は、設定画面を閉じるまで全文処理を待機する。設定画面を開いていない状態でPro状態が変わった場合は、同じ条件を満たす作品へ全文処理を要求する。

自動フォーマットをオフにして設定画面を閉じた場合は、本文を変更しない。

### 実行と表示

`ManuscriptFormattingCoordinator`は現在の本文、検証済み設定、作品ID、Pro状態をスナップショットにして、MainActor外で全文を整形する。設定シートが閉じた後の作業画面中央に`ProgressView`と「フォーマット中」を表示する。

処理中も古い結果を安全に破棄できるよう、次のいずれかが変わった場合は結果を書き戻さない。

- 作品ID
- 本文
- フォーマット設定
- Pro状態
- 全文フォーマットの世代番号

作業画面の本文入力は全文処理中も利用できる。処理中に本文が変わった場合、実行中の古い結果は破棄し、最新本文の入力が短時間落ち着いた後に全文処理を1回だけ再要求する。同期的な全文処理を重ねて開始せず、古い処理が終了してから最新スナップショットを処理する。「フォーマット中」は最新本文への処理が完了するまで表示する。

別作品への移動では現在の処理と再要求をキャンセルする。新しい全文フォーマット要求は既存の待機中要求を置き換え、最新の1件だけを残す。

## 共通設定の変更確認

### 永続化する状態

`AppData`へ`userDefaultSettingsRevision`を追加する。共通のデフォルト設定画面または発行者情報画面を開いた時点の設定と、閉じた時点の検証済み設定が異なる場合、設定セッションにつき1回だけ更新番号を増やす。画面内で複数項目を変更しても、閉じるまで更新番号は増やさない。

`ManuscriptDocument`へ`reviewedUserDefaultSettingsRevision`を追加する。これは作品が最後に適用または非適用を選んだ共通設定の更新番号を表す。

既存データでは両方を`0`として読み込む。移行直後には確認ダイアログを出さず、今後共通設定が初めて変更されて更新番号が進んだ時点から対象にする。

新規作品は既存の新規作品初期化規則を通して最新の共通設定を取り込み、作成時の更新番号を`reviewedUserDefaultSettingsRevision`へ保存する。

### 作品を開く操作

作品を選択したとき、作品の確認済み番号が共通設定の更新番号より古い場合は、作品へ移動する前に中央の角丸アラートを表示する。

- 「適用して開く」
- 「適用せず開く」
- 「キャンセル」

「適用して開く」では、エディタ、印刷、フォーマット、奥付を含む検証済み共通設定全体を作品設定へコピーし、確認済み番号を最新へ更新して作品を開く。適用後の自動フォーマットがオンの場合は、作品を開いた後に全文フォーマットを要求する。

「適用せず開く」では作品設定と本文を変更せず、確認済み番号だけを最新へ更新して作品を開く。同じ共通設定について次回以降は再確認しない。

「キャンセル」では作品選択、作品設定、本文、確認済み番号を変更しない。

共通設定を変更した時点で既に開いている作品には即時適用しない。次に作品一覧からその作品を開くときに確認する。

## サークルロゴ

### 選択UI

有料版のサークルロゴ行では、ボタン名を「アップロード」へ変更する。ボタンの直下に次の補足を小さい副次色の文字で表示する。

> ロゴはモノクロを推奨します。

選択方法の`confirmationDialog`は削除し、画面中央へ表示される角丸のネイティブアラートへ置き換える。

- 「写真から選択」
- 「ファイルから選択」
- 「キャンセル」

アラートから写真またはファイルのピッカーへ切り替える際は、既存の排他的な`CircleLogoImportPresentation`を維持する。古いアラートのdismiss通知が、選択済みのピッカー状態を消さないようにする。

### SVG

ファイルインポーターの許可形式へ通常画像に加えて`UTType.svg`を明示する。写真ピッカーは従来どおり写真ライブラリの画像を対象にする。

SVGはシステムの画像デコーダーで検証し、縦横比と透明背景を維持して長辺2048pxのPNGへ変換する。保存形式をPNGへ統一することで、既存の`circleImageData`、設定保存、プレビュー、PDF描画、画像品質確認を変更せず利用する。

極端な縦横比でも長辺は2048pxを超えず、短辺は1px以上にする。幅または高さを取得できないSVG、デコードできないSVG、PNG変換できないSVGは無効画像として扱う。

通常のPNG、JPEGなどは従来どおり画像として検証し、元データを保存する。

### 失敗とキャンセル

写真・ファイル選択のキャンセルでは設定を変更せず、エラーを表示しない。読み込み、セキュリティスコープアクセス、画像検証、SVG変換のいずれかに失敗した場合は既存のロゴを保持し、「画像を読み込めませんでした」アラートへ理由を表示する。

## 性能

- 入力確定ごとの処理は局所範囲だけとし、本文全体の複数回走査を行わない。
- 本文全体のフォーマットは設定画面を閉じた後、共通設定を適用した後、または必要なPro状態変更後に限定する。
- 同じ設定セッションから全文処理を複数回開始しない。
- 全文処理はMainActor外で実行し、最新スナップショットだけを書き戻す。
- SVG変換はアップロード時の1回だけ行い、プレビューやPDF生成のたびに再変換しない。
- 全用紙サイズ、全文字サイズのサンプルPDF一括生成は今回の検証で実行しない。

## テスト方針

実装はテスト先行で進め、少なくとも次を検証する。

### 入力時フォーマット

- 日本語変換中は本文を整形しない。
- 変換確定、通常入力、削除、貼り付け、ツールバー挿入で局所整形を行う。
- 句読点、括弧、三点リーダー、ダッシュ、感嘆符・疑問符、閉じかっこ前の句点を入力位置周辺で変換する。
- 連続空行と改ページタグを局所範囲で整える。
- 本文の離れた位置を変更しない。
- 文字数が変わる変換後もカーソルとスクロール位置を維持する。
- 自動フォーマットがオフ、または無料状態の有料ルールは適用しない。

### 設定終了時フォーマット

- 設定画面内の変更では本文を整形しない。
- 変更した設定画面を閉じると全文処理を1回だけ開始する。
- 自動フォーマットがオフ、対象外の設定だけが変更された場合、または設定が変わっていない場合は開始しない。
- 処理中に「フォーマット中」を表示し、完了後に消す。
- 作品、本文、設定、Pro状態が変わった古い結果を反映しない。
- 処理中に本文を編集した場合は古い結果を破棄し、入力が落ち着いた後に最新本文を1回だけ再処理する。

### 共通設定

- 共通設定を1回開いて複数変更しても更新番号は1回だけ増える。
- 共通の発行者情報画面を閉じた場合も、変更があれば更新番号を1回だけ増やす。
- 変更がなければ更新番号を増やさない。
- 未確認の既存作品を開くと確認が必要になる。
- 適用時は共通設定全体と確認済み番号を保存し、自動フォーマットがオンなら全文処理を要求する。
- 非適用時は作品設定と本文を保持し、確認済み番号だけを保存する。
- キャンセル時は何も変更しない。
- 新規作品は最新の共通設定と確認済み番号を持ち、確認を要求しない。
- 旧データは移行直後に確認を要求せず、次の共通設定変更から対象になる。

### サークルロゴ

- 「アップロード」とモノクロ推奨文を表示する。
- 中央の選択アラートから写真・ファイルの各ピッカーへ遷移できる。
- ファイル選択でSVGを許可する。
- 透過SVGを長辺2048px以下の透過PNGへ変換できる。
- 通常画像は元データを保持する。
- 変換後データをプレビューとPDF描画で使用できる。
- 無効SVG、無効画像、読み込み失敗時に既存ロゴを保持する。

最終確認では対象テスト、全XCTest、Debug・Staging・Releaseビルドを実行する。システムピッカー内部を自動操作できない場合は、選択アラートの表示と状態遷移、インポーター境界を自動テストで確認する。
